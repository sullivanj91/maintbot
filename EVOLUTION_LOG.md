# EVOLUTION_LOG.md

Capability changelog for the Autopilot self-evolution loop.

**Append-only.** Records every capability improvement proposed by the weekly
self-evolution session: what was proposed, whether it was accepted or rejected,
and what the outcome was. This prevents re-proposing rejected ideas.

The self-evolution loop never self-merges into main. Every proposal produces a
PR for human review. The human merge (or rejection) is recorded here.

---

## Format

```
## YYYY-MM-DD: <short description>
Proposed from: <LEARN-NNN> (seen in N repos)
PR: #<number>
Status: open | merged YYYY-MM-DD | rejected YYYY-MM-DD | WONTDO
Result: <outcome summary>
```
